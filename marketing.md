# Attendance Application

Attendance Application is an internal employee attendance system designed to help organizations track attendance accurately and securely.

## Key Features
- Employee attendance and departure recording
- Location-based attendance verification
- Attendance history view for employees
- Admin-controlled user accounts
- Secure and reliable data handling

## Who Is This App For?
This app is intended for company employees only.
Accounts are created and managed by administrators.

## Location Usage
The app requests device location only when recording attendance or departure to verify work location.
